# Jhanjhat

A tiny 8-bit phool shop. Decorate your shopfront, collect a new flower from the mandi every day, and tie a bouquet with a message for someone.

Flowers and notes come from fieldwork with the vendors of Chhatarpur Flower Market, Delhi. A Karyashalla project by Tamim Ashraf.

## What's in this folder

- `index.html`: the whole game in one file (art, code and styles)
- `README.md`: this note

The only thing loaded from outside is the two pixel fonts (Press Start 2P and Pixelify Sans) from Google Fonts. Each player's shop is saved in their own browser.

## Put it on GitHub Pages

1. Create a new repository on GitHub, for example `jhanjhat`.
2. Click **Add file → Upload files** and drag in `index.html` and `README.md`. Click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, and save.
4. After a minute the game is live at `https://<your-username>.github.io/jhanjhat/`.

It works the same on Netlify Drop, Vercel or any static host: upload this folder as it is.
